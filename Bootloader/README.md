# תיעוד קוד המעטפת (Bootloader / base.c)

קובץ זה מפרט את אופן הפעולה של קוד המעטפת המעודכן (`base.c`).

---

## 🎯 מטרת המעטפת
קוד המעטפת משמש כשלד המערכת עבור לוח **DevboxV1** (מבוסס בקר CH552).
הוא מאפשר לשלב את הקוד הנוצר מהבלוקים של התלמיד (`student_setup()` ו-`student_loop()`) יחד עם מנגנון שליטה ובדיקה מרחוק דרך חיבור ה-USB Serial.

---

## 🔄 תהליך הרצה ואתחול

### 1. הגדרות ראש (`#define`)
* הקוד שנוצר על ידי גנרטור הבלוקים כולל הגדרות פינים בראש הקוד, כגון `#define BUTTON_PIN 15`, `#define SERVO_PIN 14`, `#define BUZZER_PIN 15`.
* המעטפת משתמשת ב-DEFINES אלו (`#ifdef`) באופן אוטומטי כדי לדעת איזה פינים לשמש בבדיקות.

### 2. אתחול (`setup()`)
* מבוצעת השהיה של 1000 מילי-שניות (שנייה אחת) להתייצבות תקשורת ה-USB.
* נשלחת הודעת פתיחה בסריאל:
  ```text
  DevboxV1 initiated successfully!
  ```
* נקראת הפונקציה `student_setup()` להפעלת מנגנוני האתחול של התלמיד.

### 3. לולאה ראשית (`loop()`)
* בודקת ומבצעת פקודות Serial במידה והתקבלו.
* מריצה ניהול מצבי רקע (Non-blocking).
* מריצה את הקוד הראשי של התלמיד ב-`student_loop()`.

---

## 📡 פקודות תקשורת טורית (USB Serial Commands)

בכל סיבוב של הלולאה הראשית (`loop()`), המעטפת בודקת פקודות בסריאל (ללא תלות במספר הפורט, תוך שימוש ב-DEFINES של התלמיד):

| פקודה | תיאור | פעולה בחומרה | תגובה בסריאל |
| :--- | :--- | :--- | :--- |
| `ST` | **Stop All** | מחזיר למצב מנוחה (`IDLE`), מכבה את הפינים הפעילים. | `Stopped` |
| `BT` | **Check Button** | מגדיר את `BUTTON_PIN` כ-`INPUT` וקורא את מצבו. מכיוון שהכפתור מחובר למתח (VCC), בלחיצה הפין מקבל מתח גבוה (`HIGH`). | `h` (High / לחוץ)<br>`l` (Low / משוחרר) |
| `BZ` | **Buzzer** | מפעיל את `BUZZER_PIN` כ-`OUTPUT` במצב זמזם (`mode = 3`). | - |
| `SV` | **Servo Real Test** | מפעיל את `SERVO_PIN` כ-`OUTPUT` במצב סרוו אמיתי (`mode = 1`) ומייצר פולסי PWM של 50Hz (תזמון של 1000us ל-0 מעלות ו-2000us ל-180 מעלות, מתחלף כל שנייה). | - |

---

## ⏱️ מנגנון ניהול מצבים ברקע (Non-blocking State Machine)

* **מצב זמזם (`BZ` - מצב 3):** הפין משנה את מצבו (`TOGGLE`) כל **3,000 מילי-שניות (3 שניות)**.
* **מצב סרוו (`SV` - מצב 1):** מיוצרים פולסי סרוו תקינים של 50Hz (כל 20ms). רוחב הפולס מתחלף בין 1000µs (0°) ל-2000µs (180°) כל **1,000 מילי-שניות (שנייה)**.

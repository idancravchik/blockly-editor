# מדריך 04: הגדרת סרגל הכלים והקטגוריות (categories.json)

סרגל הכלים (Toolbox) מארגן את הבלוקים הזמינים לפי נושאים בצורה מסודרת ונוחה לבחירה על ידי המשתמש.
כל ההגדרה מנוהלת בקובץ JSON בודד בשם `categories.json` הנמצא בתיקיית `app/src/main/assets/`.

---

## 📄 מבנה הקובץ `categories.json`

הקובץ מכיל מערך של אובייקטי קטגוריה:

```json
[
  {
    "id": "gpio",
    "name": "פינים ו-GPIO",
    "color": "#4CAF50",
    "blocks": [
      "gpio_set",
      "gpio_read"
    ]
  },
  {
    "id": "timing",
    "name": "תזמון והשהיות",
    "color": "#FF9800",
    "blocks": [
      "delay_ms"
    ]
  },
  {
    "id": "control",
    "name": "לולאות ובקרה",
    "color": "#2196F3",
    "blocks": [
      "loop_forever",
      "repeat_times"
    ]
  }
]
```

---

## 🔍 פירוט שדות הקטגוריה

| שם השדה | סוג | חובה? | תיאור |
| :--- | :--- | :--- | :--- |
| `id` | מחרוזת | כן | מזהה ייחודי של הקטגוריה (באנגלית, למשל `gpio`, `sensors`) |
| `name` | מחרוזת | כן | שם הקטגוריה שיוצג בכפתור (Chip) למעלה (תומך בעברית ואנגלית) |
| `color` | מחרוזת HEX | כן | צבע הכפתור והכותרת (למשל `#4CAF50`, `#FF5722`) |
| `blocks` | מערך מחרוזות | כן | רשימת ה-`type` של הבלוקים שיוצגו בפלטה בעת בחירת הקטגוריה |

---

## 🎯 כיצד הממשק פועל?
1. **סרגל עליון (Category Chips)**: הרכיב מייצר אוטומטית שורת כפתורים מעוצבים בגלילה אופקית עבור כל קטגוריה, לפי הצבע והשם שהוגדרו.
2. **פלטת בחירה צדדית (Flyout Palette)**: בעת לחיצה על קטגוריה, הרשימה הצדדית מציגה מיד את הבלוקים השייכים אליה עם צבעיהם המקוריים ושמם.
3. **הוספה ללוח בלחיצה אחת**: לחיצה על בלוק בפלטה מוסיפה אותו מיידית למרכז שדה הראייה הנוכחי של המשתמש בלוח!

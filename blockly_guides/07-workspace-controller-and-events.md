# מדריך 07: אירועים, עדכונים חיים ובקרה

ספריית Blockly Android מאפשרת תגובה מיידית לכל אינטראקציה של המשתמש: גרירת בלוק, חיבור מגנטי, שינוי ערך בשדה, או מחיקת בלוק.

---

## 🔔 האזנה לשינויים בלוח (OnWorkspaceChangedListener)

באמצעות ממשק זה ניתן לעדכן תצוגה מקדימה של הקוד בזמן אמת, לבדוק תקינות פקודות או להציג חיווי למשתמש:

```java
blocklyView.setOnWorkspaceChangedListener(() -> {
    // מופעל אוטומטית בכל שינוי בלוח!
    String liveCode = blocklyView.generateCode();
    tvLiveCodePreview.setText(liveCode);
});
```

---

## 🛠️ פעולות שליטה מרכזיות ב-BlocklyView

| מתודה | תיאור |
| :--- | :--- |
| `generateCode()` | מפיק ומחזיר מחרוזת קוד מלאה מכל הבלוקים שבלוח |
| `clearWorkspace()` | מוחק את כל הבלוקים מהלוח ומנקה את המסך |
| `saveWorkspaceToJson()` | מחזיר מחרוזת JSON המייצגת את מצב הלוח |
| `loadWorkspaceFromJson(json)` | טוען לוח בלוקים מלא ממחרוזת JSON |
| `getWorkspace()` | מחזיר את אובייקט ה-`Workspace` לשליטה ישירה במודל |
| `getCodeGenerator()` | מחזיר את אובייקט מחולל הקוד לרישום תבניות דינמיות |

---

## 🧹 מחיקת בלוקים
1. **כפתור פח אשפה מובנה**: בתחתית המסך קיים כפתור פח (`🗑`). לחיצה עליו מוחקת את הבלוק שנבחר או מנקה בלוקים לא רצויים.
2. **ניקוי כללי**: ניתן להפעיל `blocklyView.clearWorkspace()` מכל כפתור באפליקציה שלך.
